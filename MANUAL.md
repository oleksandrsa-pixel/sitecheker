# Rank Peek — мануал по установке и настройке

Расширение для Chrome, которое каждый день проверяет позиции твоих сайтов в Google
**по твоим брендовым ключам в нужных гео**, шлёт алерт в Telegram, если сайт вылетел из
топа, и показывает конкурентов в выдаче. Всё работает в твоём браузере — без прокси,
без API, бесплатно.

---

## Быстрый старт за 5 минут

1. Распаковать архив → в Chrome загрузить папку `browser-extension` (раздел 1).
2. Создать Telegram-бота через @BotFather, узнать свой Chat ID, вставить в расширение (раздел 2).
3. Заполнить свой список сайтов в `template.csv` и загрузить его (раздел 3).
4. Включить настройки (медленный режим + ночная пауза + ежедневный отчёт) и нажать «Прохід» (раздел 4).
5. Смотреть позиции в **📊 Звіт** и конкурентов в **👥 Конкуренти**, алерты приходят в Telegram (раздел 5).

---

## 1. Установка расширения

1. **Распакуй архив** в постоянную папку (например `Документы/RankPeek`).
   ⚠️ Не держи её в «Загрузках»/временных папках — если удалишь папку, расширение перестанет работать.
2. Открой в Chrome адрес: `chrome://extensions`
3. Вверху справа включи **Режим разработчика** (Developer mode).
4. Нажми **Загрузить распакованное** (Load unpacked) → выбери папку **`browser-extension`**.
5. Появится иконка-лупа 🔎 на панели. Готово.

> Когда придёт новая версия — просто замени файлы в папке и нажми **🔄 (Reload)** на карточке
> расширения в `chrome://extensions`. Настройки и данные при этом не теряются.

## 2. Подключение Telegram (алерты)

### Шаг 1. Создай бота
1. В Telegram открой **@BotFather** → команда **/newbot**.
2. Задай имя бота и username (должен заканчиваться на `bot`, например `myrankpeek_bot`).
3. BotFather пришлёт **токен** вида `123456789:ABCdef...` — скопируй его.

### Шаг 2. Узнай свой Chat ID
1. **Напиши своему боту любое сообщение** (например «привет») — это обязательно, иначе бот
   не сможет тебе писать.
2. Узнай Chat ID любым способом:
   - **Проще всего:** напиши боту **@userinfobot** → он пришлёт твой числовой ID.
   - **Или:** открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
     (вставь свой токен вместо `<ТОКЕН>`) → найди `"chat":{"id":ЧИСЛО}` → это твой Chat ID.

### Шаг 3. Вставь в расширение
1. Кликни иконку 🔎 → откроется окно.
2. В блоке **📣 Telegram-алерти + авто-прохід** вставь:
   - **Bot token** — токен от BotFather.
   - **Chat ID** — твой числовой ID.
3. Нажми **Тест Telegram** — должно прийти тестовое сообщение. Пришло → всё верно.
4. Нажми **Зберегти + увімкнути**.

## 3. Список сайтов (CSV)

Открой файл **`template.csv`** и впиши свои проекты. Нужны всего **4 колонки**:

```
Domain,keyword,second keyword,GEO
https://yourbrand-casino.es/es-es/,yourbrand,yourbrand casino,Spain
yourbrand2.it,yourbrand2,yourbrand2 casino,Italy
```

- **Domain** — ссылка на сайт (можно полный URL или просто домен). Обязательно.
- **keyword** — основной запрос (обычно название бренда). Обязательно.
- **second keyword** — второй запрос (обычно «бренд casino»). Не обязательно.
- **GEO** — страна: `Spain, Italy, France, Portugal, Greece, Germany, Brazil, United Kingdom,
  Poland, Netherlands, Austria, Switzerland, Belgium, Ireland, Canada, Romania, Hungary,
  Sweden, Norway, Finland, Denmark, Turkey, Mexico, Chile, Argentina, Japan, India`
  (или 2-буквенный код: es, it, fr…). Обязательно.

Дубликаты убираются автоматически. Каждый ключ = отдельная проверка (бренд + бренд casino = 2 цели).

**Загрузка:** в окне расширения раскрой **📄 Список сайтів (CSV / JSON)** → **Завантажити CSV**
→ выбери свой файл. Увидишь «Завантажено ✓ N сайтів, M цілей».

> Если откроешь CSV в Excel и всё в одной колонке — это локаль Excel. Файл из шаблона уже
> открывается колонками (в нём есть служебная строка `sep=,`). На загрузку в расширение это
> не влияет.

## 4. Настройки (рекомендуемые — чтобы не ловить бан Google)

В блоке **📣 Telegram-алерти + авто-прохід**:

- ✅ **Повільний режим (drip): 1 запит кожні `4` хв** — медленный человеческий темп.
- ✅ **Нічна пауза з `23` до `7`** — ночью не проверяет (≈16 активных часов).
- **Алерт, якщо сайт випав нижче топ-`5`** — порог (5 = алерт, если сайт вылетел ниже #5 по всем ключам).
- ✅ **Щоденний звіт у Telegram о `9`:00** — раз в сутки сводка.
- Нажми **Зберегти + увімкнути**.

Затем нажми **▶ Прохід** — запустится первый проход.

> **Важно:** компьютер должен быть включён в дневные часы, а Chrome — открыт (можно свернуть).
> Один браузер/IP спокойно тянет ~200–300 проверок в день. Полный проход по ~100 целям
> занимает ~7–8 часов, потом повторяется по кругу.

## 5. Что и где смотреть

- **📊 Звіт** — таблица всех сайтов: позиция по каждому ключу, статус (🟢 в топе / 🔴 поза топ /
  ⏳ проверяю), динамика «вчера → сегодня», кто сейчас #1. Есть экспорт в CSV.
- **👥 Конкуренти** — по каждому запросу весь топ выдачи: **твой сайт подсвечен зелёным**,
  остальные помечены (конкурент / агрегатор), у каждого **полная ссылка + кнопка копировать**
  (удобно слать на абузу). Есть экспорт в CSV.
- **Telegram** — мгновенный алерт, когда сайт **вылетел из топ-N по ВСЕМ своим ключам**
  (если держится хотя бы по одному ключу — не беспокоит), и ежедневная сводка в 9:00.

## Если словил ошибку 403 / капчу

Это временный бан IP от Google (бывает при слишком частых запросах). Что делать:
- **Подожди** пару часов (IP «остынет») — расширение само встанет на паузу.
- Или **смени IP**: раздача интернета с телефона (4G) или VPN.
- Не запускай проверки залпом — медленный режим (drip) как раз для этого.

---

## Частые вопросы

- **Обязательно ли держать комп включённым?** Да, пока Chrome закрыт/комп спит — проверки не идут.
- **Сколько сайтов потянет?** Комфортно ~100–150 целей в день на одном IP. Больше — растягивай
  интервал или дроби список.
- **Второй ключ показывается как «очікує»** — это нормально: медленный проход ещё не дошёл до
  него. Через один полный круг (~8 ч) заполнится всё.
