# Rank Peek — «моя видача» SERP tracker

Читає видачу Google **рівно так, як бачиш її ти** (твоя сесія, логін, гео-розширення) —
жодного зовнішнього API, проксі чи footprint. Два режими:

- **Пасивний overlay:** на будь-якій відкритій видачі показує позицію твоїх доменів.
- **Авто-прохід:** сам відкриває кожен `кейворд + гео` зі списку, зчитує позицію,
  людський темп, і шле результат у трекер (ingest).

## Встановлення / оновлення

1. Chrome → `chrome://extensions`
2. Увімкни **Developer mode**.
3. **Load unpacked** → вибери теку `browser-extension`.
4. ⚠️ Після кожної зміни файлів тисни **🔄 Reload** біля розширення (особливо після
   оновлення `manifest.json` — інакше нові дозволи/фоновий воркер не підхопляться).

## Авто-прохід (головне)

1. Клікни іконку розширення → відкриється popup.
2. Список сайтів — розгорни **Список сайтів (CSV / JSON)** → **Завантажити CSV** і кинь
   свій файл. **Досить 4 колонок:**

   ```
   Domain,keyword,second keyword,GEO
   https://zoccer-online-casino.com/es-es/,zoccer,zoccer casino,Spain
   magneticslotcasino.com,magneticslots,magneticslots casino,Portugal
   ```

   Обов'язкові тільки **Domain** і **keyword** (+ **GEO** або `language_code`, щоб знати
   яку країну питати). Решта — необов'язкові:
   - **Brand** — лише підпис у таблиці; якщо колонки нема, візьму з `keyword`.
   - **second keyword** — друга ціль по тому ж сайту.
   - `is_active` — якщо є, беру лише `TRUE`; якщо колонки нема — всі активні.
   - `location_name`, `language_code`, `depth` — з повного формату теж читаються
     (depth ігнорується); повний експорт-CSV трекера заливається без змін.

   Розширення саме: витягне hostname з URL, розгорне `keyword` + `second keyword` в
   окремі цілі, змапить країну → `gl/hl` (Italy→it, Greece→gr/el, France→fr, Spain→es,
   Portugal→pt, Brazil→br/pt-BR, …; також приймає 2-літерний код країни), і **прибере
   дублі** (той самий домен×кейворд×країна рахується один раз). Заголовки — будь-яким
   регістром, є синоніми (`url`/`website` = Domain, `country`/`location` = GEO, `kw` =
   keyword…). Розділювач визначається сам (кома / крапка з комою / таб), рядок `sep=,`
   на початку — пропускається. Кожен новий CSV перезаписує список. (Або редагуй цілі як
   JSON вручну.)

   > **Excel показує все в одній колонці?** Це локаль Excel (він чекає `;`, а файл із
   > комами). Файли, які **експортує** розширення, і наданий шаблон уже мають службовий
   > рядок `sep=,` — Excel відкриває їх одразу колонками. Якщо робиш свій файл із нуля —
   > лиши цей перший рядок, або відкривай через **Дані → З тексту/CSV**. На імпорт це не
   > впливає: розширення читає і з комою, і з `;`.
3. Натисни **▶ Запустити прохід**.
4. Розширення по черзі відкриває фонові вкладки Google (не крадуть фокус), зчитує позицію,
   закриває, робить паузу (дефолт ~20 с + рандом, плюс довга пауза кожні 20 запитів), іде
   далі. Пауза налаштовується (див. «CAPTCHA та блокування»).
5. У popup — живий прогрес і таблиця `сайт / кейворд / гео / позиція`. **📊 Звіт** — зведена
   таблиця по всіх сайтах; **⭳ CSV / JSON** — експорт.

Кожен результат одразу POST-иться на `ingest URL`. Якщо трекер ще не запущений — нічого
страшного, результати лишаються в розширенні (видно в таблиці + експорт).

## CAPTCHA та блокування (403) — як воно тепер працює

Google не можна «обійти» програмно — автоматичного розв'язувача капчі тут нема (це був би
обхід анти-бот захисту). Замість цього розширення **рідше провокує** перевірки і **коректно
реагує**, коли вони таки з'являються:

- **Рандомна пауза** між запитами (jitter ±35%) — темп не виглядає механічним.
- **Довга пауза кожні N запитів** (за замовч. кожні 20 → 3 хв), щоб ~200 сайтів не йшли
  одним безперервним сплеском (саме це найчастіше й тригерить ліміти Google).
- **Детект блокування**: якщо Google показав CAPTCHA / сторінку `/sorry/` / consent —
  прохід **стає на паузу** саме на цій цілі, вкладка з перевіркою **виходить на передній
  план**, і ти розв'язуєш капчу **один раз вручну** → прохід **сам продовжується** з тієї ж
  цілі. Якщо тебе нема за компом — **авто-повтор через N хв** (налаштовується, дефолт 30).
- **М'яке блокування**: кілька помилок/таймаутів поспіль → авто-пауза (cooldown), а не
  безглузде «довбати» далі й поглиблювати бан.
- Про паузу приходить **Telegram-повідомлення** (якщо налаштований) і системне сповіщення.

Налаштування анти-блоку — у popup → **Список сайтів (CSV / JSON)**: пауза між запитами,
розмір батча + тривалість довгої паузи, пауза після блокування.

> Якщо Google вже видав **403 на весь IP** («Your client does not have permission…»,
> «That's an error») — це лікується лише **часом або зміною IP** (VPN / мобільний
> інтернет / перепідключення роутера з динамічним IP). Такий 403 віддається прямо на
> `/search` — розширення його розпізнає, стає на паузу і пробує знову після cooldown, але
> **саме́ розблокувати IP не може** — це поза межами будь-якого скрипта. Головне — не
> женися по великому списку занадто швидко; для сотень цілей на день дивись «Масштабування».

## Масштабування (коли сайтів багато і щодня)

Обмеження — **кількість запитів до Google з одного IP на добу**. Один браузер/IP витримує
приблизно **200–300 брендових запитів на день** у людському темпі; більше — впираєшся в
403/CAPTCHA. Варіанти:

- **Розтягнути в часі (drip):** роздати весь список рівномірно на весь день (≈1 запит на
  5–8 хв), а не залпом. Безкоштовно, але стеля ~200–300/день і комп має бути ввімкнений.
- **Google Search Console API:** якщо сайти **твої** й підтверджені в GSC — офіційний API
  віддає позиції по всіх запитах і країнах **без скрейпінгу, без CAPTCHA, без проксі**,
  масштаб до тисяч. Мінуси: позиція *середня*, затримка ~2 дні, конкурентів не показує.
- **Платний SERP-API / SaaS-трекер:** провайдер сам крутить проксі й капчу (~$0.5–2 за
  1000 запитів). Гроші в обмін на масштаб і нуль возні.
- **Гібрид:** GSC для обсягу по своїх сайтах + розширення для «живої» видачі та
  конкурентів по ключових.

## Звіт по позиціях (структуровано)

Кнопка **📊 Звіт** у popup відкриває окрему сторінку з **зведеною таблицею**: один рядок на
сайт+гео, а позиції по кожному кейворду — окремими колонками (**Кейворд 1**, **Кейворд 2**, …).
Тобто «зайшов і одразу бачиш сайт, гео і його позицію по кожному ключу» — на відміну від
плаского CSV, де кожен кейворд був окремим рядком і все зливалось.

Показує **обидва ключі** кожного сайту окремими колонками — навіть ті, що ще не перевірені
(позначені «— / очікує», бо повільний drip ще не дійшов до них). Біля назви сайту —
**статус сайту**: 🟢 в топі (хоча б по одному ключу) / 🔴 поза топ-5 (по всіх ключах) /
⏳ перевіряю. Це той самий статус, за яким шлються Telegram-алерти.

Можливості сторінки звіту:

- Картки-підсумки: сайтів усього, **сайтів у топі**, **сайтів поза топ**, перевірок,
  ключів у топ-5, помилки.
- Пошук по сайту/домену/гео/кейворду, фільтр **тільки проблемні** (сайт поза топ-5 по
  ВСІХ ключах), сортування кліком по заголовку колонки.
- Кольорові пігулки позицій (#1-3 зелений, #4-5 жовтий, нижче/OUT червоний), наведення на
  пігулку показує, **хто зараз #1** по цьому запиту.
- **Історія / динаміка**: під кожною позицією — стрілка зміни (🟢▲ вгору / 🔴▼ вниз) і
  рядок **«вчора: #N»** (позиція ~24 год тому). Наведення на позицію показує останні
  перевірки: `#5 → #5 → #4 → #3`. Видно, сайт **росте, стоїть чи падає**.
- **⭳ CSV (структурований)** — та сама зведена таблиця у файл (сайт, домен, гео, а на
  кожен кейворд: сам кейворд + позиція + «вчора» + зміна), відкривається в Excel рівно
  так, як бачиш.

## Конкуренти (окрема вкладка)

Кнопка **👥 Конкуренти** у popup відкриває окрему сторінку — так само структуровано, як
звіт, а не «купою» в CSV. По кожній цілі: **бренд · кейворд · гео · моя позиція** (кольорова
пігулка) і **топ-5 конкурентів** із їхньою позицією в SERP, доменом (клікабельний) і
заголовком сторінки. Свої домени й «шум» (wikipedia, trustpilot, app store, соцмережі)
виключаються. Є пошук, фільтр по гео, фільтр **«тільки де я поза топ-5 / OUT»** і
**⭳ CSV** (той самий структурований експорт, відкривається колонками в Excel). Дані
беруться з останньої перевірки кожного сайту — відкрив будь-коли.

## Обмеження

- Позиція рахується по блоку органіки (`#rso`); рекламу/PAA/відео не рахує окремо —
  для брендових запитів коректно.
- Гео = параметр `gl` з твого IP (те, що ти зараз і бачиш). Для «справжньої країни» —
  окреме VPN-перемикання (не в цій версії).
- Комп має бути ввімкнений під час проходу. Якщо Google покаже CAPTCHA/consent —
  ціль запишеться як `err` (тоді збільш паузу між запитами).
- Alarms Chrome можуть трохи розтягувати паузи (мін. ~30 с) — це навіть безпечніше.

## Telegram-алерти + авто-прохід кожні 4 год

Popup → блок **Telegram-алерти + авто-прохід**:

1. **Bot token** — створи бота в [@BotFather](https://t.me/BotFather) (`/newbot`) → скопіюй токен.
2. **Chat ID** — напиши боту будь-що, тоді відкрий
   `https://api.telegram.org/bot<TOKEN>/getUpdates` → візьми `chat.id`
   (або скористайся [@userinfobot](https://t.me/userinfobot)).
3. **Топ-N** — поріг алерту (5 = алерт, якщо сайт випав нижче #5 або зник).
4. Постав галочку **Авто-прохід кожні 4 год** → **Зберегти + увімкнути**.
5. **Тест Telegram** — має прийти тестове повідомлення.

Алерти рахуються **по САЙТУ, а не по кожному ключу**. Сайт вважається «в топі», якщо він
у топ-N хоча б **по одному** зі своїх ключів. Алерт про виліт приходить **лише коли сайт
випав із топ-N по ВСІХ своїх ключах**; якщо він тримається хоча б по одному ключу — тиші,
без спаму. І навпаки — коли повертається в топ хоча б по одному ключу, приходить «повернувся».

```
🔴 Nvcasino · France
Випав із топ-5 по ВСІХ ключах
Найкраща позиція: #8
🕒 2026-07-22T13:00:00Z
https://nvcasino-frances.com
```
```
🟢 Betscore · Italy
Знову в топ-5: #3
```

Алерт спрацьовує на **зміні стану сайту** (був у топі → випав по всіх ключах; і навпаки).
Технічні збої (CAPTCHA/consent) по одному ключу не алертять. Chrome має бути відкритий.

### Повільний режим (drip) + нічна пауза + щоденний звіт

Найм'якший режим проти блокувань — **повільний людський темп із нічною паузою**, а не
залп. Це прямо б'є по єдиному сигналу, що тебе банить: сплеск запитів з одного IP.

- Галочка **«Повільний режим (drip): 1 запит кожні N хв»** (дефолт 4) — розширення робить
  один запит раз на ~3–5 хв (N ± рандом), **по колу**, і **щоразу рандомізує порядок**
  цілей (щоб потік не був фіксованою сигнатурою трекера з побудовним `gl/hl`). Заміняє
  «авто-прохід кожні N год».
- Галочка **«Нічна пауза з HH до HH»** (дефолт 23→7) — вночі перевірки не йдуть узагалі
  (≈16 активних годин удень). Знижує і добовий обсяг, і «робот-цілодобово»-патерн.
- Галочка **«Щоденний звіт у Telegram о HH:00»** — раз на добу зведення по всіх сайтах
  поза топ-N із динамікою «вчора → сьогодні» та поміткою, скільки цілей не перевірено
  (сон/блокування). Просто відкрив і подивився.

`num=10` завжди (ніколи `num=100`). Комп має бути ввімкнений у активні години.

> Стеля одного браузера/IP — приблизно **200–300 запитів на добу**. Для ~114 цілей
> повільний drip із нічною паузою працює комфортно (≈1 повний прохід за ~7–8 год удень);
> коли список виросте більше — дивись «Масштабування».

### Дайджест щопроходу (нагадування, а не разово)

Окрім миттєвих алертів на зміну стану, наприкінці **кожного** проходу приходить
**зведене повідомлення** з усіма **сайтами**, що зараз поза топ-N **по всіх ключах**
(найкраща позиція по сайту в дужках):

```
⚠ Rank Peek — сайтів поза топ-5 (по всіх ключах): 2 (у топі: 21)
• Nvcasino · France — поза топ-5 (найкраща: #8)
• Casea · Greece — поза топ-5 (найкраща: OUT)
🕒 22.07 13:00
```

Тобто про проблемний сайт нагадує **щоразу**, поки він не повернувся хоча б по одному
ключу, — а не лише в той прохід, коли він уперше випав. Якщо всі сайти в топі — коротке
«✅ проблемних нема». Вимикається галочкою **«Нагадувати про всі сайти поза топом
щопроходу»** (за замовч. увімкнено). Довгий список ріжеться на кілька повідомлень.
