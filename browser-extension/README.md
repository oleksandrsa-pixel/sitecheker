# Rank Peek — «моя видача» SERP tracker

Читає видачу Google **рівно так, як бачиш її ти** (твоя сесія, логін, гео-розширення) —
жодного зовнішнього API, проксі чи footprint. Два режими:

- **Пасивний overlay:** на будь-якій відкритій видачі показує позицію твоїх доменів.
- **Авто-прохід:** сам відкриває кожен `кейворд + гео` зі списку, зчитує позицію,
  людський темп, і шле результат у трекер (ingest).

## Встановлення / оновлення

1. Chrome → `chrome://extensions`
2. Увімкни **Developer mode**.
3. **Load unpacked** → вибери теку `browser-extension`.
4. ⚠️ Після кожної зміни файлів тисни **🔄 Reload** біля розширення (особливо після
   оновлення `manifest.json` — інакше нові дозволи/фоновий воркер не підхопляться).

## Авто-прохід (головне)

1. Клікни іконку розширення → відкриється popup.
2. Список сайтів — розгорни **Налаштування** → **Завантажити CSV** і кинь свій файл у
   форматі `GEO, Brand, Domain, keyword, second keyword, location_name, language_code,
   depth, is_active`. Розширення саме: візьме тільки `is_active=TRUE`, витягне hostname з
   URL, розгорне `keyword` + `second keyword` в окремі цілі, змапить країну → `gl/hl`
   (Italy→it, Greece→gr/el, France→fr, Spain→es, Portugal→pt, Brazil→br/pt-BR, …).
   Кожен новий CSV просто перезаписує список. (Або редагуй цілі як JSON вручну.)
3. Натисни **▶ Запустити прохід**.
4. Розширення по черзі відкриває фонові вкладки Google (не крадуть фокус), зчитує позицію,
   закриває, робить паузу (~25-30 с), іде далі. 10 цілей ≈ 5 хв.
5. У popup — живий прогрес і таблиця `сайт / кейворд / гео / позиція`. **⭳ JSON** — експорт.

Кожен результат одразу POST-иться на `ingest URL`. Якщо трекер ще не запущений — нічого
страшного, результати лишаються в розширенні (видно в таблиці + експорт).

## Обмеження

- Позиція рахується по блоку органіки (`#rso`); рекламу/PAA/відео не рахує окремо —
  для брендових запитів коректно.
- Гео = параметр `gl` з твого IP (те, що ти зараз і бачиш). Для «справжньої країни» —
  окреме VPN-перемикання (не в цій версії).
- Комп має бути ввімкнений під час проходу. Якщо Google покаже CAPTCHA/consent —
  ціль запишеться як `err` (тоді збільш паузу між запитами).
- Alarms Chrome можуть трохи розтягувати паузи (мін. ~30 с) — це навіть безпечніше.

## Telegram-алерти + авто-прохід кожні 4 год

Popup → блок **Telegram-алерти + авто-прохід**:

1. **Bot token** — створи бота в [@BotFather](https://t.me/BotFather) (`/newbot`) → скопіюй токен.
2. **Chat ID** — напиши боту будь-що, тоді відкрий
   `https://api.telegram.org/bot<TOKEN>/getUpdates` → візьми `chat.id`
   (або скористайся [@userinfobot](https://t.me/userinfobot)).
3. **Топ-N** — поріг алерту (5 = алерт, якщо сайт випав нижче #5 або зник).
4. Постав галочку **Авто-прохід кожні 4 год** → **Зберегти + увімкнути**.
5. **Тест Telegram** — має прийти тестове повідомлення.

Далі розширення саме проганяє всі сайти кожні 4 год і **одразу шле персональний алерт**
по кожному сайту, що змінив стан:

```
🔴 Nvcasino · France · «Nvcasino»
⬇ Випав із топ-5
Позиція: #1 → #8
🕒 2026-07-22T13:00:00Z
https://nvcasino-frances.com
```
```
🔴 Casea · Greece · «Casea»
❌ ЗНИК із видачі
Позиція: #1 → немає у видачі
```
```
🟢 Betscore · Italy · «Betscore»
Повернувся в топ-5: #3
```

Алерт спрацьовує на **зміні стану** (був у топі → випав; і навпаки — повернувся), тому
спаму немає. Технічні збої (CAPTCHA/consent) не алертять. Chrome має бути відкритий.

## Далі (опційно)

Ендпоінт `POST /ingest/serp` у застосунку прийме ці ж результати → snapshot → пайплайн
Stage 7 (Claude-аналіз причин + щоденний зведений звіт). Але для «випав із топ-5 → алерт»
цього вже достатньо — усе працює в розширенні.
