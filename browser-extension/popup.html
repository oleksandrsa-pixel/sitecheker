❓ Як це працює
  1. Завантаж CSV зі своїми сайтами (розділ «Список сайтів»).
  2. Встав Telegram token + Chat ID, увімкни авто-прохід.
  3. ▶ Прохід — розширення відкриває Google по кожному кейворду у твоєму браузері (твоя сесія + гео) і читає позицію з екрана.
  4. Далі саме кожні N год проганяє все і порівнює з минулим разом.
  5. Якщо сайт випав нижче топ-N або зник → миттєвий Telegram-алерт.

Chrome має бути відкритий. Гео = параметр gl з твого IP.
