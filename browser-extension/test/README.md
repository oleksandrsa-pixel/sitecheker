# Rank Peek — тести

Функціональні тести розширення. Ганяють **реальний код** (`background.js`,
`content.js`, `popup.js`, `report.js`) у Node з підробленими `chrome.*`, DOM і
`fetch` — без браузера. Залежностей нема, лише Node.

```bash
node test/sweep.test.js   # оркестратор: прохід, дайджест, історія, блокування, cooldown
node test/ui.test.js      # report.js (пивот/тренд/CSV), popup.js (CSV-імпорт/експорт), content.js (парсинг/детект блоку)
```

Кожен файл друкує `N passed, M failed` і виходить із кодом 1, якщо є падіння.

Що покрито:

- **sweep.test.js** — повний прохід і запис результатів; Telegram-дайджест
  **щопроходу** + разовий transition-алерт; all-clear / only-errors дайджести;
  історія/«вчора»/тренд; блокування через повідомлення content-скрипта →
  пауза → ручне розв'язання → продовження; блокування через редірект на
  `/sorry/` (onUpdated); м'який блок (2 таймаути → cooldown); зупинка чистить
  алярми; захист від «битих» цілей.
- **ui.test.js** — зведена таблиця (групування по сайт+гео, порядок кейвордів,
  колонки-стрілки/«вчора», структурований CSV); маппінг гео→gl/hl, парсинг
  CSV-списку (пропуск `is_active=FALSE`, розгортання second keyword), експорт
  результатів і конкурентів (виключення власних доменів + «шуму»); парсинг
  органіки (пропуск самого google-хоста, збереження піддоменів, дедуп) і
  детект «unusual traffic».
