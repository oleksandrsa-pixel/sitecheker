Drop Finder — отслеживаем дропы через Google Таблицу

Пошаговый гайд для того, кто видит это впервые: от установки расширения до первого прогона и Telegram-алертов. Делается один раз, минут за 15.

🌐 Нужен: Chrome 📧 Google-аккаунт ⏱ ~15 минут 💬 Telegram — по желанию
Что это вообще делает. Ты ведёшь таблицу с дроп-доменами по проектам. Расширение само открывает Google в нужной стране, ищет по бренду и показывает, какие твои дропы уже попали в топ-10. Всё — в твоём браузере, под твоей сессией.

1 Установить расширение

  1. Распакуй архив drop-finder в любую папку (её нельзя потом удалять — расширение читает файлы оттуда).
  2. Открой в Chrome адрес chrome://extensions
  3. Включи справа вверху переключатель «Режим розробника».
  4. Нажми Завантажити розпаковане и выбери папку drop-finder.
  5. В панели появится иконка 🎯 — это и есть Drop Finder. Готово.
Совет. Нажми на «пазл» справа от адресной строки и «пришпиль» иконку 🎯, чтобы она была всегда под рукой.

2 Получить Google API-ключ

Ключ нужен, чтобы расширение могло читать твою таблицу (только читать). Это бесплатно.

  1. Зайди на console.cloud.google.com под своим Google-аккаунтом.
  2. Вверху создай проект: селектор проектов → New Project → любое имя → Create.
  3. Включи нужный API: открой страницу Google Sheets API → кнопка Enable.
  4. Создай ключ: APIs & Services → Credentials → Create credentials → API key.
  5. Скопируй ключ вида AIza… — он понадобится в шаге 5.
Важно. Выбирай именно «API key». Не «Help me choose», не «OAuth client», не «Service account» — они для другого и не подойдут.
Безопасность. После создания нажми Restrict key → в «API restrictions» выбери Google Sheets API. Тогда ключ сможет читать только таблицы и ничего больше.

3 Открыть доступ к таблице

  1. Открой свою Google Таблицу.
  2. Справа вверху «Поділитися» (Share).
  3. В «Загальний доступ» выбери «Усі, хто має посилання» → роль «Читач».
  4. Скопируй ссылку на таблицу — пригодится в шаге 5.

4 Заполнить таблицу по шаблону

Правила простые:

  • Каждая вкладка = один проект (бренд + гео). Первая строка — заголовки.
  • Колонки: domain, brand, Type, geo.
  • domain — это сами дроп-домены. brand — бренд (по нему идёт поиск). geo — код страны: FR, IT, ES, PT, GR…
domainbrandTypegeo
meuse-internet.frGamblerinamonobrandFR✱
carpes-koi.frGamblerinamonobrandFR
vioben.frGamblerinamonobrandFR

Пример вкладки «Gamblerina FR». В колонке domain — твои дропы. Достаточно поставить одну * в любой клетке — и вся вкладка идёт в работу.

Как отметить проект для проверки. Поставь * (звёздочку) в любой клетке вкладки — или добавь * в её название. Убрал * → проект перестаёт отслеживаться при следующей синхронизации.
Почему «*», а не «+». Ячейка, которая начинается с +, превращается в Google Таблицах в формулу и ломается. Со звёздочкой такого нет.

5 Подключить таблицу в расширении

  1. Нажми иконку 🎯 → раздел «📊 Google Таблиця».
  2. Вставь ссылку на таблицу и API-ключ из шагов 2–3.
  3. Поставь галочку «Авто-синхронізація» (например, каждые 30 мин).
  4. Поле доп. слова оставь как есть — там уже casino (запрос будет «бренд» и «бренд casino»).
  5. Нажми Зберегти + увімкнути, затем Синхронізувати зараз.
Как понять, что сработало. Внизу появится строка вроде «Готово ✓ 1 вкладок · 1 проєктів · 2 запитів · 6 дропів». Если там нули — смотри раздел «Частые проблемы».

6 Запустить прогон и смотреть дропы

  1. Нажми 🎯 Прогін дропів. Бот сам откроет Google в нужных странах и прочитает топ-10. Вкладки закрываются сами — не трогай их во время прогона.
  2. Когда статус покажет, что проход завершён — нажми 👁 Дропи.
  3. По каждому проекту видно топ-10 и какие твои дропы туда попали (точное совпадение по домену).

Что значат метки в результатах:

Дроп Ваш сайт Конкурент Агрегатор / Іньше
Если Google показал CAPTCHA. Просто реши её в открывшейся вкладке — прогон продолжится сам. Чтобы капчи было меньше — не запускай слишком часто и не помечай * лишние проекты.

7 Telegram-алерты о новых дропах по желанию

Чтобы получать сообщение, когда новый дроп появился в топ-10:

  1. Создай бота: в Telegram открой @BotFather → команда /newbot → задай имя → он выдаст token вида 123456:ABC…
  2. Узнай свой chat_id: открой @userinfobot → /start → он пришлёт число (это и есть chat_id).
  3. Нажми Start у своего бота (того, что создал в п.1) — бот не может написать первым.
  4. В расширении раздел «📣 Telegram-алерти» → вставь token и chat_id → Зберегти → Тест Telegram.
  5. Пришло «Надіслано ✓» и сообщение в Telegram — значит всё работает.
Частые проблемы
После синхронизации — «0 вкладок / 0 проєктів»
Нигде не стоит * (поставь звёздочку в любой клетке нужной вкладки). Или в таблице нет колонок domain и brand в первой строке. Или доступ к таблице не открыт по ссылке (шаг 3).
Ошибка ключа или доступа при синхронизации
Проверь: включён ли Google Sheets API (шаг 2.3); таблица открыта «по ссылке — Читач»; ключ скопирован полностью и от того же проекта, где включён API.
Telegram: «chat not found» или тест не проходит
Чаще всего — ты не нажал Start у своего бота. Ещё: chat_id должен быть числом (не @username), а token — без пробелов. Новый тест теперь пишет, что именно не так — токен или chat_id.
Google всё время просит CAPTCHA / ошибка 403
Слишком много запросов подряд. Реши капчу в открытой вкладке (прогон продолжится), запускай реже и убери * с проектов, которые сейчас не нужны. Меньше активных проектов = меньше запросов.
В «Дропи» пусто после обычного прогона
Так и должно быть: вкладка «Дропи» показывает только активные бренды из таблицы. Подключи таблицу и нажми 🎯 Прогін дропів.
