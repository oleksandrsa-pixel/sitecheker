Rank Peek — позиции сайтов в Google + поиск дропов

Расширение открывает Google в твоём браузере (твоя сессия и гео) и читает реальные позиции сайтов по ключевикам. Плюс отдельный модуль дропов через Google Таблицу. Всё локально, без прокси и сторонних сервисов.

🌐 Нужен: Chrome 📄 Список сайтов (CSV) 💬 Telegram-бот — для алертов 📊 Google Таблица — для дропов
Как это устроено в двух словах. Ты даёшь список «сайт + ключевик + страна». Расширение по очереди ищет каждый в Google, запоминает позицию и сравнивает с прошлым разом. Если сайт выпал из топа — присылает алерт в Telegram. Дропы — отдельно: их список берётся из твоей Google Таблицы.

1 Установить расширение

  1. Распакуй архив с расширением в постоянную папку (её нельзя удалять — Chrome читает файлы оттуда).
  2. Открой chrome://extensions
  3. Включи справа вверху «Режим розробника».
  4. Нажми Завантажити розпаковане и выбери папку расширения.
  5. Появится иконка 🔎 Rank Peek. «Пришпиль» её через «пазл» у адресной строки.
Главное правило. Chrome должен быть открыт во время проходов — расширение работает через твой браузер, а не на сервере.

Часть 1 · Позиции сайтов

2 Загрузить список сайтов

Открой иконку 🔎 → раздел «📄 Список сайтів (CSV / JSON)» и загрузи CSV. Достаточно 4 колонок:

Brand — необязательно (возьмётся из keyword). Полный формат (Brand, location_name, language_code…) тоже читается. Дубли убираются сами.

Здесь же — настройки против блокировок (можно оставить по умолчанию):

  • Пауза між запитами, сек — меньше = быстрее, но выше риск CAPTCHA (норм: 20).
  • 🛡 Анти-блок: довга пауза кожні N запитів и её длительность — периодический «перекур».
  • Пауза після блокування / CAPTCHA, хв — на сколько встать на паузу после блокировки.

Нажми Зберегти. Список появится в таблице вверху попапа.

3 Первый прогон

  1. Нажми ▶ Прохід. Расширение начнёт по очереди открывать Google по каждому ключевику в его стране и читать позицию с экрана.
  2. Вкладки открываются и закрываются сами — не мешай во время прохода. Прогресс виден в строке статуса.
  3. Если Google покажет CAPTCHA — реши её в открытой вкладке, проход продолжится сам.
Про гео. Страна выдачи определяется параметром gl и твоим IP. Хочешь видеть выдачу конкретной страны как местный — используй её через свой VPN/локацию.

4 Смотреть отчёт по позициям

  • 📊 Звіт — таблица по каждому сайту: позиция, статус «у топі» / «поза топ-5», сравнение с прошлым разом. Есть поиск и фильтр по гео.
  • 📅 Вчора — тот же отчёт, но с позициями примерно сутки назад (удобно сравнить «было/стало»).
  • ⭳ CSV / ⭳ JSON — выгрузка результатов для Excel или бэкенда.

Прямо в попапе тоже есть мини-таблица целей с последней позицией — её заголовок-строку можно свернуть, если список длинный.

Часть 2 · Telegram-алерты и авто-прогон

5 Подключить Telegram и автопрогон

Сначала создай бота и узнай chat_id:

  1. В Telegram: @BotFather → /newbot → имя → получишь token (123456:ABC…).
  2. @userinfobot → /start → пришлёт chat_id (число).
  3. Нажми Start у своего бота — иначе он не сможет тебе написать.

Потом в разделе «📣 Telegram-алерти + авто-прохід»: вставь token и Chat ID и настрой, что нужно:

  • Алерт, якщо сайт випав нижче топ-N — впиши число (напр. 5): пришлёт сообщение, когда сайт упал ниже топ-5 или исчез.
  • Нагадувати про всі сайти поза топом щопроходу — дайджест всех «выпавших» после каждого прохода.
  • 🎯 Алерти про дропи — писать, когда в топ-10 активного бренда появился новый дроп (см. Часть 3).
  • Авто-прохід кожні N год — сам прогоняет весь список каждые N часов.
  • Повільний режим (drip) — 1 запрос каждые N минут, целый день. Самый мягкий режим против блокировок.
  • Нічна пауза з … до … — не беспокоить и не слать запросы ночью.
  • Щоденний звіт о … :00 — раз в день присылать сводку в Telegram.
  • 🎯 Окремий прогін активних брендів кожні N год — чаще проверять только бренды-дропы (домены должны быть и в общем списке).

Нажми Зберегти + увімкнути, затем Тест Telegram — должно прийти «Надіслано ✓».

Рекомендуемый безопасный режим. Включи Повільний режим (drip) ~1 запрос в 3–5 мин + Нічна пауза. Это самый низкий риск CAPTCHA. Chrome при этом должен быть включён.

Часть 3 · Дропы (Google Таблица)

6 Google API-ключ и доступ к таблице

Нужен один раз, чтобы расширение читало твою таблицу.

  1. console.cloud.google.com → создай проект (New Project).
  2. Включи API: Google Sheets API → Enable.
  3. APIs & Services → Credentials → Create credentials → API key → скопируй AIza…
  4. В самой таблице: «Поділитися» → «Усі, хто має посилання — Читач».
Важно. Выбирай именно «API key» (не «Help me choose», не OAuth, не Service account). После создания можно Restrict key → Google Sheets API для безопасности.

7 Заполнить таблицу по шаблону

  • Каждая вкладка = проект (бренд + гео). Первая строка — заголовки.
  • Колонки: domain, brand, Type, geo. В domain — сами дроп-домены; geo — код страны (FR, IT, ES…).
domainbrandTypegeo
meuse-internet.frGamblerinamonobrandFR✱
carpes-koi.frGamblerinamonobrandFR
Как отметить проект. Поставь * в любой клетке вкладки (или в её названии) — вся вкладка идёт в работу. Убрал * → перестаёт отслеживаться.
Почему «*», а не «+». Ячейка, начинающаяся с +, превращается в формулу и ломается. Со звёздочкой такого нет.

8 Подключить, синхронизировать и смотреть дропы

  1. Раздел «📊 Google Таблиця (авто-дропи)»: вставь ссылку + API-ключ, включи Авто-синхронізацію, доп. слово оставь casino.
  2. Зберегти + увімкнути → Синхронізувати зараз. Должно показать «✓ N вкладок · N проєктів · N запитів · N дропів».
  3. Нажми 🎯 Прогін дропів — прогон только по активным брендам из таблицы.
  4. Открой 🎯 Дропи — по каждому проекту видно топ-10 и какие твои дропы туда попали (точное совпадение по домену).

Частые проблемы
Google постоянно просит CAPTCHA / ошибка 403
Слишком много запросов подряд. Реши капчу в открытой вкладке (проход продолжится), увеличь паузу між запитами, включи drip и нічну паузу, убери лишние проекты. Меньше запросов = меньше блокировок.
Telegram: «chat not found» или тест не проходит
Чаще всего — не нажал Start у своего бота. Ещё: chat_id должен быть числом, а token — без пробелов. Тест теперь пишет, что именно не так — токен или chat_id.
Синхронизация таблицы — «0 вкладок / 0 проєктів»
Нигде не стоит *; или нет колонок domain/brand в первой строке; или таблица не открыта «по ссылке — Читач»; или не включён Google Sheets API.
Во вкладке «Дропи» пусто
Там показываются только активные бренды из таблицы. Подключи таблицу, синхронизируй и нажми 🎯 Прогін дропів. Обычный ▶ Прохід сюда ничего не добавляет.
Позиции не обновляются сами
Включи Авто-прохід (или drip) в разделе Telegram и держи Chrome открытым. Вручную обновляет кнопка ▶ Прохід.
