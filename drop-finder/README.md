# Drop Finder

Лёгкое расширение **только для поиска дропов** из Google Таблицы. Это урезанная
версия Rank Peek: без основного списка сайтов, отчётов, ночной паузы и drip —
только подключение таблицы, кнопка прогона и просмотр дропов.

## Что делает
1. Читает твою Google Таблицу (все вкладки, новые подхватываются сами).
2. Вкладка берётся в работу, если в **любой её клетке** (или в названии) стоит `*`.
   Формат вкладки: `domain, brand, Type, geo`, где `domain` — сами дроп-домены.
3. По каждому активному проекту делает **два запроса** — «бренд» и «бренд casino»
   (доп. слово настраивается) — в нужном гео, читает топ-10 в **твоём** браузере.
4. На странице **👁 Дропи** показывает, какие из твоих дропов уже в топ-10
   (точный збіг по домену) + подсветку по ᐉ-шаблону для незнакомых.
5. (Опц.) шлёт в Telegram новые дропи.

## Установка
1. `chrome://extensions` → включи **Режим розробника**.
2. **Завантажити розпаковане** → выбери папку `drop-finder`.

## Настройка (один раз)
1. **Google API-ключ (только чтение):** console.cloud.google.com → создай проект →
   включи **Google Sheets API** → *Create credentials → API key*. Ключ читает
   только твои таблицы.
2. Таблицу открой «Все, у кого есть ссылка — Читатель».
3. В попапе (📊 Google Таблиця): вставь ссылку + ключ → **Зберегти + увімкнути** →
   **Синхронізувати зараз**. Должно показать «✓ N вкладок · N проєктів · … дропів».

## Использование
- **🎯 Прогін дропів** — запускает прогон по активным брендам из таблицы.
- **👁 Дропи** — открывает страницу с результатами.

## Заметки
- Прогон работает, пока открыт Chrome; вкладки закрываются сами.
- Чем больше проектов помечено `*`, тем больше поисковых запросов → выше риск
  403/CAPTCHA. Не ставь слишком часто.
- Движок (`background.js`, `content.js`, `drops.html/js`) — общий с Rank Peek,
  поэтому оба расширения можно держать рядом; хранилища у них раздельные.
